# Parent-Pal

Bạn đồng hành nuôi con cho phụ huynh Việt: trò chuyện thay cho điền form, có trí nhớ về từng bé, và giúp phụ huynh **thực thi** việc nuôi dạy con theo kiến thức có nguồn.

Repo này hiện **chỉ chứa tài liệu**. Code bản thử (Expo, AI giả lập bằng luật tiếng Việt) đã được gỡ ngày 28/10/2026; xem lại trong lịch sử git tại commit `9abc286`.
