## Review notes

- `CONDITIONAL` means the feature applies only when the context and verified authorization permit; it does **not** mean the gate is passed.
- A0/A1 school-rubric features must not silently transform caregiver observations into academic scores; age-appropriate observation belongs to a different capability.
- Reviewers/operators/service identities are never automatically authorized merely by role label; authorization is resource-, purpose-, and action-scoped.
- Child-directed/youth UX never overrides consent, guardian conflicts or privacy restrictions; legal authority and age-of-majority transitions remain MR-016/MR-017 blockers.
- Each L4 must inherit or override the module contract in `Feature_3_2_L4_Pilot_Three_Modules_REVIEW.md`; if a row is wrong, record a candidate-specific issue before P6.
